## Objetivo

Após o upgrade 60→63, concentrar tokens e defaults SP, reduzir o diff dos arquivos de tema do core vs upstream e deixar as listas da EDD-1356 refletindo a classificação real.

## O que foi feito

1. **Linha de base** — métricas no manifesto; higiene de listas (entradas obsoletas, doc datagrid).
2. **Módulo SP** — `ui/colors/constants/sp-theme.ts` + `types/sp-color-keys.ts` (`restore-ours`). `light.ts` / `dark.ts` / `color-keys.ts` = upstream + gancho mínimo; accents e `SP_PALETTE_COLORS` saem do módulo SP.
3. **`groups.ts`** — restaurado ao upstream (fallbacks SP eram workaround; `color("accentN")` já resolve SP).
4. **Classificação** — 20 FE de `sp-extra` → 14 `dual-changed` + 6 `behavior-manual`; `sp-extra` só infra/marca/`locales/metabase.po`.
5. **Correções laterais na mesma branch** — `.github`/`.gitignore` alinhados; patch AGPL; Scalar (`t`); `triggerEvent` sem efeito no `axis.ts`.

Smoke visual do tema claro após o Passo 2: OK (login, home, charts, pickers).

## Adiado / multi-cliente

Renomear `--mb-color-sp-*` no CSS do core para tokens semânticos do Metabase (`text-secondary`, etc.) **não** faz parte do fechamento. Com um só cliente SP, o valor já está no `sp-theme`; a troca de nomes exige FE e só ganha peso se houver outros temas/clientes.
